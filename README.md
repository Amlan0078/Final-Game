# ORBITAL

**Live site:** [final-game-iota.vercel.app](https://final-game-iota.vercel.app/)

ORBITAL is a space-themed project with two modes:

- **Duel:** a local two-player saucer arena, with an option to fight a computer opponent.
- **Observatory:** an interactive solar system with planetary orbits, a follow camera, and time controls.

The experience runs locally in the browser and does not require sign-in.
